# Workflow: Merging Datasets

This subfolder explains how Regrow and CSB fields are spatially joined with DISES farmer survey data and with the 9 supplementary farmland characteristic blocks. It covers the merge methodology, match-quality scoring, representative-field assignment, and how to combine the standalone output tables into a single analysis-ready dataset.
