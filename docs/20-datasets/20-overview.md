# Dataset Documentation

This subfolder is the primary reference for understanding the four datasets that feed into the pipeline: Regrow, CSB, DISES, and supplementary farmland characteristics. Each file explains what the dataset is, how it is structured, what variables it contains, and how it is processed by the pipeline.
