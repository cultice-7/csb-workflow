# Regrow–DISES Merge Script

**`join_regrow_dises.py`**: Implements the spatial overlay joining Regrow fields to DISES farmer holdings — spatial overlay with buffer margin, largest-overlap selection, area/crop match-quality scoring, and representative-field tiering. See [Merging Regrow with DISES and Supplements](../30-workflow/31-merging-regrow-dises-supplements.md) for the full methodology.
